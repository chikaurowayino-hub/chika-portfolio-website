How to add your own content

  1. A YouTube video: open js/media-data.js, find the video and paste the link inside youtubeUrl: "".
  2. A PDF or PowerPoint: copy the file into the media folder, then set file: "media/your-file.pdf".
  3. An image: copy it into the images folder and write its path in image.
  4. My own intro video: save it as media/intro.mp4 and change intro-placeholder.mp4 to intro.mp4 in media.html.
